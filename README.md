# AlexNet-CoinClassification

This project fine-tunes a pretrained AlexNet backbone with a custom fully-connected classifier head to distinguish coins for the DL4CV Coin classification competition Kaggle.
The [dataset](https://www.kaggle.com/competitions/dl4cv-coin-classification/data) comes with many challenges such as class imbalanced and subtle differences. 
The notebook has been optimized and covers the full pipeline: data loading, preprocessing, model definition, training, and evaluation.
